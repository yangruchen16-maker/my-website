9/5學習心得

我學到什麼

  • CSS 的基本語言
  • 把另一個檔案與主要檔案做連結
  • 副檔名的重要性
  • 分號的重要性

疑問

  • CSS 主要語言是 style 嗎
  • rel, stylesheet, href 的關係，如果 rel 打 style.css 會怎麼樣
  • font-family: "Helvetica Neue", Arial, "微軟正黑體", sans-serif; 這四個是什麼意思

解答

  • 那是 html 才會用到的
  • rel 是關係，href 為檔名，要說明這個是什麼和這個檔案在哪裡
  • 一個是 Mac 專用字體，另一個是 Win 專用字體，中文字體，保底， 因為逗號分隔，瀏覽器由左往右找，找不到就用下一個

原本不知道

  • 分號是用來區隔程式與程式之間，不然瀏覽器會亂掉
  • 重新整理的按鍵是 Command+R，存檔是 Command+S

現在我知道

  • CSS 規格為 選擇器 { 屬性: 值 }
  • 檔案與檔案的連接可用 link
  • 如果把分號拿掉，畫面會變成黑字且無任何變化
  • 把字體變成 Times New Roman，英文變成 Times New Roman， 中文字體才變成新細明體
