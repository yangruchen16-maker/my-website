9/12學習心得

我學到什麼

  • repository 是自己網站的檔案資料夾
  • commit、command S，一個是上傳後還可以修改，另一個是覆蓋舊檔無法復原
  • file:// 和 https://，一個是電腦裡的檔案，另一個是網路上的伺服器
  • GitHub Pages 是檔案連接到伺服器上

我原本不知道

  • 我一開始使用 GitHub 的時候，不了解 repository 是什麼
  • commit change 的意思是什麼

現在我知道

  • repository 是放入自己做的網站程式碼的地方
  • commit change 是標註這個檔案是在做什麼
