9/3學習心得

我學到什麼

  • VS Code 的基本操作：開資料夾、新增檔案、存檔
  • 副檔名決定檔案類型，.txt 和 .html 瀏覽器讀起來完全不同
  • 資料夾命名規則：用英文、不要空格、全部小寫
  • index.html 是網頁世界的預設首頁，這是全球通用的約定
  • 網址、檔名、title 是三件獨立的事

我原本不知道

  • 不知道存成 txt 會讓瀏覽器讀不出來
  • 以為網址上會顯示我設定的 title

現在我知道

  • 我自己動手把 HTML 打進 VS Code 並成功在瀏覽器打開
  • 不是靠 AI 幫我寫好
  • 親眼看到 h1 h2 p 在畫面上分層，證明標籤真的有作用
  • title 不在網址上，而在瀏覽器分頁的標籤列
  • file:// 開頭代表這個檔案只存在我的電腦裡，
  • 別人打不開，要放上 GitHub 才會有真正的網址
