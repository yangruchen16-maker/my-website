9/19學習心得

我原本不會

  • <> 的寫法
  • <li>要不要列每個項目
  • note.html 和 note-0902.html 是同一個頁面嗎

我學到什麼

  • 小於號要打成 <，大於號要打成 >
  • <li> 是分一個項目，而 <p> 是連續一句話， 兩者差異是一個是列表式，另一個是一句話
  • 複習架構 <head> 和 <body> 分開，不要包在一起

我現在知道

  • 我雖然知道架構，但還是會忘記， 所以要依靠邏輯思考不硬背
  • 要記得套用視覺效果的檔案， 不然會與有套用的頁面不同
  • 之後要新增筆記時，要多增加一個 note-幾月幾號， 打完筆記後，要記得打 href 的 note 主頁， 而且 note 主頁也要打 href 的 note-幾月幾號

疑問

  • 若把 note 主頁裡的 index 連結打入
      會怎樣？ 會與 note-幾月幾號並排嗎

    • 會並排，但建議分開，因為首頁不是一篇筆記

  • 之後要新增文章時，主頁要連結其他頁面， 我要在 GitHub 上增加嗎

    • 不是。在電腦上改完再上傳， GitHub 是倉庫，不是工作檯
